# Setup

1. Copy the contents of this folder into the `chiragjangiir` profile repository.
2. Ensure the repository is named exactly `chiragjangiir` and is public.
3. In repository **Settings → Actions → General**, allow GitHub Actions to read and write repository contents so the scheduled workflow can commit the refreshed SVG.
4. Run **Actions → Update GitHub network visual → Run workflow** once, or wait for the daily schedule.
5. The workflow uses the built-in `GITHUB_TOKEN`; no personal access token should be needed if repository workflow permissions allow contents write.

The terminal SVG is generated locally with `python3 scripts/boot.py`. The network SVG is generated by `scripts/network.py` in GitHub Actions.
